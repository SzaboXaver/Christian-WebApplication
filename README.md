# Christian-WebApplication

The project in this repository is called *Christian-WebApplication*. This project uses **TypeScript** as foundation, **NodeJS** for the backend and **React** for the frontend side. I used **Supabase** for my database. The project also uses the OSM (Open Street Map) as the map engine, and also the Overpass and the Nominatim databases.

**!WARNING!** In the alpha and beta versions, I directly removed the database's publishable key and the project URL. This is because in these versions the website isn't ready for public usage! Thank you for your understanding!

This project is versioned with Git tags (e.g. v0.1.0). To switch between versions:
```bash
git checkout v0.1.0
```

## v0.1.0

### Features:
  - Login
  - Registration
  - Searching for churches in Hungary

### Requirements
  - An IDE, e.g. Visual Studio Code
  - [Node.js](https://nodejs.org/)

### Commands
  - npm install
  - npm run dev

### Getting started
**GIT SETUP**
1. Clone the repository:
```bash
git clone https://github.com/SzaboXaver/Christian-WebApplication.git
cd Christian-WebApplication
```

2. Navigate into the backend folder:
```bash
cd Christian-WebApplication-backend
```

3. Install the dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm run dev
```

5. **Open a second terminal**, in the repository root:
```bash
cd Christian-WebApplication-Frontend
```

6. Install the dependencies:
```bash
npm install
```

7. Start the development server:
```bash
npm run dev
```

**Other way**
1. Download all the files from the repository.
2. Open these files in the IDE, e.g. Visual Studio Code.
3. In its terminal, write the following commands for the backend:
```bash
cd Christian-WebApplication-backend
npm install
npm run dev
```
4. Open a second terminal in the repository root and write the following commands for the frontend:
```bash
cd Christian-WebApplication-Frontend
npm install
npm run dev
```
